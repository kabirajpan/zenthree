# Task Planning

## Purpose

Use this Skill to clarify scope and organize work before implementation.

## Workflow

1. Restate the requested outcome and observable acceptance criteria.
2. Inspect the workspace to discover its language, framework, build system, conventions, and relevant architecture.
3. Identify affected files, dependencies, interfaces, risks, and validation steps.
4. Break the work into small ordered steps with explicit dependencies.
5. Separate required work from optional follow-ups.
6. Review the plan for unnecessary scope and missing verification.

## Rules

- Do not assume a language, framework, build system, or project convention.
- Keep the plan proportional to the request.
- Prefer reversible, incremental changes.
- Record unresolved questions instead of hiding uncertainty.
